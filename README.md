BenchDeck

A neat and customizable homepage to store all your favorite links and quick access options in one place.

About

BenchDeck is a personal dashboard initiative aimed at creating an organized and navigable tab without any unwanted clutter.

Goals

Keep frequently used links close at hand.

Make the layout simple and easy to use.

Leave room for personal styling and customization.

Try BenchDeck Online

No account or installation is required to try the deployed version on my website.

Live Website: https://benchdeck.vercel.app/

Run BenchDeck Locally

If you want to run it locally, follow these steps:

Clone the BenchDeck repository.

Open the project folder.

Open index.html in your browser, and it will work.

BenchDeck is built with HTML, CSS, and JavaScript, so there is no package installation or build command required for this version.

Make BenchDeck Your New Tab Page

Some browsers don't let you set a custom New Tab page directly in their built-in settings. You can use a browser extension for this.

Install New Tab Redirect.

Open the extension's settings or Options page. You can usually access it through the extension menu or the three-dot menu.

Set the redirect URL to your preferred public link: https://benchdeck.vercel.app/.

Save your settings.

Open a new tab to test it.

If it doesn't work in Brave, make sure the extension is enabled at brave://extensions.
